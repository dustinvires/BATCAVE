# BATCAVE Philosophy

BATCAVE exists to create a home that is safe, reliable, comfortable, efficient, maintainable, and understandable.

Technology should reduce stress, not create it.

Every automation must have a purpose.

Every device must be documented.

Every system should fail safely.

Whenever practical, systems should continue functioning without cloud connectivity.

Documentation is considered part of the installation.

A project is not complete until it has been documented.
